## 격차 분석 — 5가지 기준

### 1. 공감 유발력 (감정적 연결)

| | AI 초안 | 골든 출력 |
|---|---|---|
| 카피 | "肌荒れでお悩みの方へ、オンラインで専門家に相談できます。" | "肌荒れ、一人で悩まないで。" |
| 특징 | 정보 전달형, 서비스 설명 중심 | 감정 공감형, 고객의 심리 상태를 먼저 건드림 |

**격차:** 초안은 서비스를 설명하지만, 골든은 고객이 느끼는 외로움·막막함에 먼저 공감한다. 일본 고객은 직접적 광고보다 공감에서 신뢰를 형성하는 경향이 강함.

**→ 3주차 제약 조건 후보:** "카피는 반드시 고객의 감정 상태(불안·고민·외로움)를 1문장으로 반영한 뒤 해결책으로 연결할 것"

---

### 2. 슬라이드 구성의 서사 흐름

| | AI 초안 | 골든 출력 |
|---|---|---|
| 구성 | 타이틀→원인→서비스→방법→CTA (정보 나열) | 표지→문제 공감→해결→결과→CTA (서사 흐름) |
| 특징 | 각 장이 독립적으로 정보 전달 | 고객이 "내 이야기네" → "해결 가능하네" → "해볼까" 순서로 이동 |

**격차:** 초안의 구성은 브로슈어처럼 읽히고, 골든의 구성은 짧은 드라마처럼 읽힌다. Instagram 스와이프 콘텐츠는 서사가 있어야 끝까지 본다.

**→ 3주차 제약 조건 후보:** "슬라이드 구성은 항상 [공감→문제→해결→증거→CTA] 5장 구조 고정"

---

### 3. 캡션의 구체성과 행동 유도

| | AI 초안 | 골든 출력 |
|---|---|---|
| 길이 | 4~5줄 (짧고 간결하지만 밋밋) | 8~10줄 (구체적 이점 나열 + 이모지 활용) |
| CTA | "詳しくはプロフィールリンクから" | "プロフィールのリンクから今すぐチェックしてみてください👇" |
| 이점 나열 | 없음 | ✅ 체크마크로 3가지 구체적 이점 명시 |

**격차:** 초안 캡션은 "상담 가능"이라는 사실만 전달한다. 골든은 예약 불필요·일본어 대응·무료 등 고객이 망설이는 이유를 하나씩 지운다.

**→ 3주차 제약 조건 후보:** "캡션은 반드시 고객 망설임 해소 포인트 3개(✅ 형식)를 포함하고, CTA는 행동 동사+방향 표시(👇)로 마무리할 것"

---

### 4. 일본 시장 맥락 반영도

| | AI 초안 | 골든 출력 |
|---|---|---|
| 계절성 | 없음 | "春になると肌荒れが気になる季節🌸" — 봄 환절기 명시 |
| 타겟 연령 | 없음 | "ニキビ跡に悩む20代へ" — 명확한 대상 명시 |
| 불안 요소 해소 | 없음 | "病院に行く時間がない", "何科に行けばいいかわからない" 직접 언급 |

**격차:** 초안은 트렌드 키워드를 그대로 번역해 쓰는 수준이다. 골든은 키워드 뒤의 고객 심리(왜 이 키워드가 뜨는지)를 읽어 콘텐츠에 반영한다.

**→ 3주차 제약 조건 후보:** "각 콘텐츠에 ①계절/시기 맥락 ②타겟 연령/상황 ③주요 불안 요소 1개를 명시할 것"

---

### 5. 광고 규제 및 브랜드 안전성

| | AI 초안 | 골든 출력 |
|---|---|---|
| 효능 표현 | "専門家がサポートします" (모호하지만 무난) | "あなたの肌に合った治療法をご提案" (제안형) |
| 비포/애프터 | 언급 없음 | 명시적으로 "비포/애프터 사진 직접 사용 금지" 가이드 포함 |
| 단정 표현 | 없음 | 없음 |

**격차:** 초안은 규제 인식 자체가 없다. 골든은 이미지 가이드에 금지 표현을 명시한다. 일본 미용의료 광고는 약기법(薬機法)으로 엄격히 규제됨.

**→ 3주차 제약 조건 후보:** "효능·효과를 단정하는 표현(〜できる、〜治る、〜効果あり) 금지, 비교 전후 이미지 사용 금지"

## 요약: 3주차에 넣을 제약 조건 후보 TOP 5

| 번호 | 제약 조건 | 해결하는 격차 |
|---|---|---|
| 1 | 카피는 고객 감정 공감 → 해결책 구조 | 공감 유발력 부족 |
| 2 | 슬라이드 5장: 공감→문제→해결→증거→CTA 고정 | 서사 흐름 없음 |
| 3 | 캡션에 이점 3개(✅) + 행동 CTA(👇) 필수 | 행동 유도 약함 |
| 4 | 계절/타겟/불안 요소 각 1개씩 명시 | 일본 맥락 부재 |
| 5 | 약기법 금지 표현 리스트 적용 | 광고 규제 미반영 |
