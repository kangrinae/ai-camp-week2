# 3주차 사전과제 — 자동화 서비스 단계별 분해

---

## 확정한 선정 토픽

트렌드 키워드 1~3개 → 일본 고객 맞춤 Instagram 카드뉴스 5슬라이드 초안 + 후킹 문구 후보 3개 + 의료 광고법 위반 표현 자동 점검
산출물을 구글시트가 아닌 **웹 대시보드**로 제공 — 매일 아침 열어서 트렌드 확인 + 기획안 생성까지 한 화면에서 완결.

---

## 메일 받은 "답해 주세요" 질문 답변

**Q1. 어떤 콘텐츠를 골든으로 쓰실 건지**

실제 업무에서 직접 만든 일본향 카드뉴스 1편을 골든으로 사용합니다. 세린클리닉 Instagram용 "환절기 피부 트러블" 편으로, 공감형 카피(肌荒れ、一人で悩まないで。) → 5슬라이드 서사 구조(공감→문제→해결→증거→CTA) → 망설임 해소 캡션(✅ 이점 3개 + 👇 CTA) 형태입니다. 의료 광고법 위반 가능 표현(효능 단정·비포애프터 사진)은 골든에서 이미 제거되어 있어, AI 초안과의 주요 격차 항목으로 중점 분석할 예정입니다.

**Q2. MVP 범위 — 트렌드 조사 + 콘텐츠 기획 연결**

강사님 (a) 권장을 이해하지만, 이미 Google Apps Script로 트렌드 수집 자동화를 구현해뒀습니다(야후뉴스 RSS, 마이니치 RSS, 구글 트렌드, 야후 치에부쿠로 → 구글시트 자동 기입). Instagram·X·유튜브 등 로그인 필요 플랫폼은 검색 URL 자동 생성 + **수동 직접 입력** 방식으로 API 의존도를 낮췄습니다. 수집된 트렌드를 대시보드에서 확인하고 기획안 생성까지 연결하는 게 목표입니다.

**Q3. SNS 포맷 — 카드뉴스 선택**

카드뉴스(5슬라이드)로 확정합니다. 실제 업무에서 가장 자주 만드는 포맷이고, 슬라이드별 구조가 고정되어 AI 출력 검수가 명확합니다. 릴스·피드는 동일 워크플로로 추후 확장 예정입니다.

**Q4. 의료 광고법 위반 표현 점검 — (c) 둘 다**

CLAUDE.md(또는 프롬프트 룰북)에 약기법(薬機法) 금지 표현 리스트를 박아두고(효능 단정·비포애프터·최고 등 표현 금지), AI 출력 시 룰북을 컨텍스트로 주입해 처음부터 위반 표현을 회피하도록 합니다. 출력 후에는 금지 키워드 패턴 매칭으로 ⚠️ 플래그를 추가 표시합니다.

**Q5. 기술 스택**

OpenAI API(GPT-4o mini) + Vercel 배포로 진행합니다. 화면 구성: 자동 수집 트렌드 목록 + 수동 입력 영역 → 키워드 선택 → [기획안 생성] → 카드뉴스 5슬라이드 초안 + 후킹 문구 3개 + ⚠️ 광고법 플래그 표시. GitHub repo → Vercel 자동 배포.

## 자동화 서비스 단계별 분해

| 단계 | 내용 | 기술 | 완료 주차 |
|---|---|---|---|
| Step 1 | 트렌드 수집 — RSS·구글트렌드·야후치에부쿠로 자동 수집 + 로그인 필요 채널은 수동 입력 | Google Apps Script + 수동 | 3주차 |
| Step 2 | 대시보드 화면 — 자동 수집 트렌드 목록 + 수동 입력 영역 + [기획안 생성] 버튼 한 화면 구성 | HTML/JS 또는 Next.js | 3주차 |
| Step 3 | 카드뉴스 초안 생성 — 키워드 선택 시 슬라이드 5장 + 후킹 문구 3개 + 이미지 콘셉트 자동 생성 | OpenAI API (GPT-4o mini) | 3주차 |
| Step 4 | 의료 광고법 검수 — 금지 표현 룰북 프롬프트 주입 + 출력 후 ⚠️ 플래그 후처리 | 프롬프트 엔지니어링 + 키워드 필터 | 4주차 |
| Step 5 | Vercel 배포 — GitHub repo 연결 후 자동 배포, 매일 접속 가능한 URL 확보 | GitHub + Vercel | 4주차 |
| Step 6 | 검토·채택·발행 준비 — 광고법 최종 검수 후 채택안 확정, 피그마 이미지 제작 연결 | 사람 | 5주차 |
